== Kontextabgrenzung
=== Fachlicher Kontext

Die Anwendung wird lokal von einer einzelnen Person verwendet, um Trainingseinheiten administrieren zu können.
Es gibt keine Mehrbenutzerverwaltung oder externe Benutzerrollen. 

image::context.png[fachlicher Kontext]

=== Technischer Kontext

Das System wird lokal via Docker bereitgestellt und läuft in getrennten Containern. Der Benutzer greift über einen Standard-Webbrowser auf die Webanwendung zu.
