[[section-concepts]]
== Testkonzept
=== Backend
- Services werden mit Unittests abgedeckt. 
- Controller werden nicht getestet, um "testing the mock, not the code" zu verhindern. 
- Framework: Vitest

=== Frontend
- Components, welche Logik enthalten werden mit Unittests abgedeckt.
- Services werden mit Unit Tests getestet. 
- Framework: vitest

=== E2E
- Kritische Funktionen werden mit automatisieren E2E-Tests abgedeckt. 
- Framework: Cypress
