== Qualitätsanforderungen

Dieses Kapitel beschreibt die Qualitätsziele.

[cols="1,2", options="header"]
|===
| Qualitätsziel | Beschreibung

| Performance
| Lighthouse-Score >= 90 (Mobile & Desktop)

| Benutzbarkeit
| Responsive für Mobile/Tablet/Desktop

| Zuverlaessigkeit
| Applikation wird mit Unit-, Integrations- und E2E-Tests getestet

| Reproduzierbarkeit
| `docker compose up` startet den kompletten Stack reproduzierbar
|===

=== Lighthouse-Ergebnisse
Der Lighthouse Score wurde manuell via Chrome DevTools Lighthouse gemessen. Der Stack wurde über `docker compose up --build` gestartet. Es wurden vorgängig einige Workouts und Kategorien erfasst. Das Qualitätsziel mit einem Durchschnitt von 90 konnte erreicht werden.
